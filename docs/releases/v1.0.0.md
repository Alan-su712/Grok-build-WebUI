# Grok Build WebUI v1.0.0

Grok Build WebUI is an independent multilingual interface for the locally installed Grok Build Runtime. It is not affiliated with, sponsored by, or endorsed by xAI, Grok, or the official Grok Build project. The Grok Runtime is not included.

## Downloads

### Windows

- [Portable x64 application](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/GrokBuildWebUI-v1.0.0.exe)
- [Folder-selecting installer](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/GrokBuildWebUI-Setup-v1.0.0.exe)
- [Portable ZIP with documentation](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/GrokBuildWebUI-v1.0.0-windows-x64.zip)

The Windows desktop app requires the local Grok Build Runtime and Microsoft Edge WebView2 Runtime. Neither runtime is included in the installer.

### macOS

Choose the package matching your Mac's processor:

- Apple Silicon (`arm64`): [DMG](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/Grok-Build-WebUI-macOS-arm64-v1.0.0.dmg) · [ZIP](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/Grok-Build-WebUI-macOS-arm64-v1.0.0.zip)
- Intel (`x64`): [DMG](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/Grok-Build-WebUI-macOS-x64-v1.0.0.dmg) · [ZIP](https://github.com/Alan-su712/Grok-build-WebUI/releases/download/v1.0.0/Grok-Build-WebUI-macOS-x64-v1.0.0.zip)

Open the DMG and move `Grok Build WebUI.app` to Applications, or unzip the archive and move the app there. The desktop app bundles its Python environment; install the local Grok Build Runtime separately. These macOS builds are not signed or notarized with an Apple Developer ID. If Gatekeeper blocks the first launch, Control-click the app, choose **Open**, then confirm.

### Browser mode on Windows or macOS

Requires Node.js 18+, Python 3.10+, and the local Grok Build Runtime. Install from the GitHub source archive (this project is not published to the npm public registry):

```sh
npm install --global https://github.com/Alan-su712/Grok-build-WebUI/archive/refs/heads/main.tar.gz
grok-build-webui --open
```

The local interface opens at `http://127.0.0.1:3088/` by default. See the [English](https://github.com/Alan-su712/Grok-build-WebUI/blob/main/README.en.md), [简体中文](https://github.com/Alan-su712/Grok-build-WebUI/blob/main/README.md), [繁體中文](https://github.com/Alan-su712/Grok-build-WebUI/blob/main/README.zh-TW.md), or [日本語](https://github.com/Alan-su712/Grok-build-WebUI/blob/main/README.ja.md) guide for detailed setup and troubleshooting.
